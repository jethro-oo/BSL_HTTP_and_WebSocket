# Personal Portfolio Landing Page

## 1. Project Description

This project is my personal portfolio landing page, created for Laboratory 1 in CCC181: Application Development and Emerging Technologies. The website introduces me, Jethro Hinayon, a third-year BSIT student at MSU-IIT. It shows my personal information, hobbies, skills, projects, and contact details.

## 2. Setup & Execution Steps

 Steps to open and run the project.

### Step 1: Install the Required Tools

Bonezegei Scripting Language version 1.3.3 and Visual Studio Code are installed. Also, install the Bonezegei Scripting Language Formatter extension in VS Code.

### Step 2: Open the Project

Open Visual Studio Code and open the `BSL_HTTP_and_WebSocket` project folder. The folder contains the `app.bzg` file, the `package.json` file, and the `public` folder.

### Step 3: Open the Terminal

In VS Code, click **Terminal** and select **New Terminal**. The terminal is inside the main project folder.

### Step 4: Install the Dependencies

Command in the terminal:

`bzg install`

### Step 5: Run the Web Server

After the installation finishes successfully, type:

`bzg run`


### Step 6: Open the Website

Open your web browser, such as Google Chrome.

Enter this address in the address bar:

`http://localhost:8000/`
